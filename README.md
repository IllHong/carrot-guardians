# 당근밭 수비대

귀여운 동물들과 당근밭을 지키는 캐주얼 디펜스 게임.

**플레이:** https://illhong.github.io/carrot-guardians/

- 동물을 뽑고, 원하는 칸으로 끌어서 옮기고, 같은 동물·같은 등급 3마리를 합성
- 경쟁모드(AI 5명과 대결) · 생존모드(40라운드) · 무한모드(끝까지 버티기)
- 모바일 세로 화면 기준, 브라우저에서 바로 실행 (설치 불필요)

현재 테스트 버전: 광고 대신 3초 안내 화면이 나옵니다. 앱인토스 출시 준비 중.

## 음악
- 게임 중 배경음악: 직접 제작 (Abocado · Lyria 3 Pro)
- 시작 화면 음악: "Interior Birdecorator Menu" by Abstraction — CC0 (https://tallbeard.itch.io/music-loop-bundle)

## 앱인토스 빌드
`toss/` 폴더에서 `npm install` 후 `npm run build` → `carrot-guardians.ait` 생성 (루트 index.html에 SDK 브리지를 끼워 넣음)
